# QRESYNC (RFC 7162 section 3.2): SELECT with what the last session knew, VANISHED, UID FETCH (CHANGEDSINCE ...
# VANISHED), the [CLOSED] line between two mailboxes, and a changed UIDVALIDITY.
@ tls
S: * PREAUTH [CAPABILITY IMAP4rev1 ENABLE QRESYNC] ready
= greeted preauth
> enable qresync
C: A0001 ENABLE QRESYNC
S: * ENABLED QRESYNC

= A0001 enabled QRESYNC

# A VANISHED that cannot be read ends the session.
@ tls
S: * PREAUTH [CAPABILITY IMAP4rev1 ENABLE QRESYNC] ready
= greeted preauth
> enable qresync
C: A0001 ENABLE QRESYNC
S: * ENABLED QRESYNC
S: A0001 OK
= A0001 enabled QRESYNC
> select INBOX
C: A0002 SELECT "INBOX"
S: A0002 OK done
= A0002 selected exists=0 recent=0 flags=- permanent=- uidvalidity=none uidnext=none unseen=none modseq=none read-only=false
S: * VANISHED 1:*
! Malformed("VANISHED response")

# A server that lacks QRESYNC: the resync falls back to CONDSTORE and the UIDVALIDITY check; a VANISHED it sends
# anyway ends the session.
@ tls
S: * PREAUTH [CAPABILITY IMAP4rev1 CONDSTORE] ready
= greeted preauth
> select-with INBOX condstore known=67890007/90060115194045000 uids=1:9
C: A0001 SELECT "INBOX" (CONDSTORE)
S: * 3 EXPUNGE
S: * OK [UIDVALIDITY 1] UIDs valid
S: A0001 OK done
= expunged 3
= uidvalidity changed 67890007 -> 1
= A0001 selected exists=0 recent=0 flags=- permanent=- uidvalidity=1 uidnext=none unseen=none modseq=none read-only=false
S: * VANISHED 4
! Unexpected("VANISHED response")
