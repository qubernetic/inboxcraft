> move 1 Archive

# Without MOVE, with UIDPLUS: UID COPY, UID STORE of \Deleted, UID EXPUNGE of only these messages, one answer.
@ tls
S: * PREAUTH [CAPABILITY IMAP4rev1 UIDPLUS] ready
= greeted preauth
> select INBOX
C: A0001 SELECT "INBOX"
S: * 5 EXISTS
S: A0001 OK done
= A0001 selected exists=5 recent=0 flags=- permanent=- uidvalidity=none uidnext=none unseen=none modseq=none read-only=false
> move 42:43 Archive
C: A0002 UID COPY 42:43 "Archive"
S: A0002 OK [COPYUID 432432 42:43 7:8] Done
C: A0003 UID STORE 42:43 +FLAGS.SILENT (\Deleted)
# One command at a time, the steps of the move too.
> list
! Busy
S: A0003 OK Done
C: A0004 UID EXPUNGE 42:43
S: * 2 EXPUNGE
S: * 2 EXPUNGE
S: A0004 OK Done
= expunged 2
= expunged 2
= A0002 moved 432432 42:43 -> 7:8 by copy and expunge
# A refused copy moves nothing.
> move 44 Lists/Rust
C: A0005 UID COPY 44 "Lists/Rust"
S: A0005 NO [TRYCREATE] No such mailbox
= A0005 No [TRYCREATE] No such mailbox
# A refused STORE leaves the copy made and the message where it was.
> move 44 Archive
C: A0006 UID COPY 44 "Archive"
S: A0006 OK [COPYUID 432432 44 9] Done
C: A0007 UID STORE 44 +FLAGS.SILENT (\Deleted)
S: A0007 NO Permission denied
= A0006 moved 432432 44 -> 9 kept, not marked: No Permission denied
# A refused UID EXPUNGE leaves the message marked \Deleted.
> move 45 Archive
C: A0008 UID COPY 45 "Archive"
S: A0008 OK Done
C: A0009 UID STORE 45 +FLAGS.SILENT (\Deleted)
S: * 3 FETCH (FLAGS (\Deleted))
S: A0009 OK Done
= fetch seq=3 flags=\Deleted
C: A0010 UID EXPUNGE 45
S: A0010 BAD [CLIENTBUG] Try later
= A0008 moved kept, not expunged: Bad [CLIENTBUG] Try later
# A step's answer under the first tag ends the session.
> move 46 Archive
C: A0011 UID COPY 46 "Archive"
S: A0011 OK Done
C: A0012 UID STORE 46 +FLAGS.SILENT (\Deleted)
S: A0011 OK Done
! Unexpected("tagged response")
