# 64

## Changelog
### Security
- The IMAP client hides the base64 forms of the credentials it sent, after LOGIN as after AUTHENTICATE PLAIN: the
  PLAIN token and the password alone, of the password as sent and trimmed, each with and without its padding, are
  hidden in a server's text, an error and `Debug` output; the proptest seed that found the leak is committed (#64)

## Roadmap
- IMAP: the base64 forms of the credentials are hidden like the password (#64)

## Gaps
- The IMAP client hides the password as sent, as LOGIN quotes it and in base64 (the PLAIN token and the password
  alone); it is shown as it comes in any other encoding a server writes it back in (base64 at another offset,
  quoted-printable, percent encoding), with an invisible mark inside it, in another case of ASCII letters (as
  itself or as a base64 token), and as a token cut short (#64).
