# 305

## Changelog
### Added
- The command line across the top of the window: one field for search, commands, people and mailboxes. Plain text
  searches the mail shown as it is typed; `>` lists the window's commands, `@` the people the mail knows, `#` the
  mailboxes. `Ctrl K` and `/` open it empty, `Ctrl F` narrowed to the mailbox shown; `/` runs only while no text
  field has the keyboard. The arrows move the pick, Enter or a press runs it; one `Esc` closes the results, the
  next gives the keyboard back to where it was (#305)
- A command that cannot run here is listed with the reason and runs nothing; a plugin's command is drawn coming
  soon (#305)

### Changed
- The command palette's window and the list head's search field are gone: both are the command line's now. The
  palette's key (`ui.palette.open`) opens the command line; a new key, `ui.command.open` (`/`), does too (#305)
- The `ui_shot` key `palette` is `command` (#305)

## Roadmap
- Qubernetic look: the command line takes over the palette and the list's search (#305)

## Gaps
- Command line (#305): the results are an area of their own, not a float of the float module (whose modal layer
  would take the field's keyboard); while they show they hold the window's keys as the palette did. Tab keeps the
  keyboard in the field while the results show: the rows are reached by the arrows, not by Tab.
- Command line (#305): plain text searches the mail shown, as the list's field did; the frames' "all mail" search,
  the GO TO and LAST COMMANDS groups and the mixed results of a search (mail, people, mailboxes in one list) are not
  built. A refused command's reason shows in its row, not yet in the status line. `@` then Enter searches the
  person's mail. New message stays at the left of the command line (the frames draw none there) until the title
  bar comes; the mark and the window's controls are not drawn yet. The results' rows are the menu rows (32 high),
  their head and edge as the float module draws them; the frames' cyan edge and drop shadow are not matched.
