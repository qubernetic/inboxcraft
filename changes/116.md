# 116

## Changelog
### Added
- Drafts in the engine: `compose.new` (from the account that last sent, with its signature), `compose.update`,
  `compose.show`, `compose.list` and `compose.discard`, all `safe`; a draft is kept in the store at every change, so
  text typed before a kill is there after a restart (#116)
- Recipients are checked as typed: an impossible address is marked with what is wrong and blocks Send, like a draft
  without a recipient (#116)
- `compose.signature` (`owner`): a signature per account, swapped when a draft moves to another account (#116)
- A draft that has been still for ten seconds goes to the account's Drafts folder from `Session::tick`; each new
  copy replaces the one before it (APPENDUID), and a discarded draft's copy goes too. `mail.thread` lists the drafts
  that answer a message of the thread (#116)

## Roadmap
- Drafts that are never lost: kept at every change, copied to the Drafts folder, with the compose commands, a
  signature per account and checked recipients (#116)

## Gaps
- A draft copy goes to the server without Bcc, `In-Reply-To` or `References`; reply threading comes with M4b. On a
  server without UIDPLUS the copy before cannot be named, so it stays in the Drafts folder (#116).
- A failed draft upload is not tried again until the draft changes, and nothing calls `Session::tick` yet, so no copy
  goes up in the app until the composer and the tray join (#116).
