# 396

## Changelog
### Added
- The status line says since when the window has been offline ("offline since 14:10"), with "try again" after what
  it shows meanwhile, drawn coming soon (#396)
- Each place has its own keys at the status line's right: Home mail, calendar, write and commands; the calendar
  mail, write and commands; the settings mail and commands, and back on a page alone in one pane; the command line's
  results next, previous, run and close; one pane with a message in the list's place list (`Esc`) and commands (#396)
- An error in the status line is dismissed by `Esc` where the key reaches nothing else (no field, no surface, not
  back to the list or the sections, not on the calendar), and the line then shows `Esc dismiss` beside commands (#396)
- A status line message is a live region: a screen reader says it when it comes, an error at once (#396)

### Fixed
- With several problems the status line shows the worst first: what needs the owner (a refused sign-in, a
  certificate) before what mends itself (no connection) (#396)
- The status line counts problems, a send the server refused among them, not failing accounts, and says "and 1 more
  problem" for one (#396)
- A link in the status line ("open account", "open log") follows its fact without a `·`, as the frames draw it (#396)
- The mailbox's error that a full status queue dropped no longer stays behind unseen: it goes with it, and the same
  failure told again is shown again (#396)

## Gaps
- Status line (#396): "try again" when offline is coming soon: no command signs the accounts in before their wait
  ends. "Offline since" is the time the window first read the accounts offline, not when the connection dropped.
- Status line (#396): a send the server refused counts as a problem but is never the line's first fact; the line
  names only failing accounts there.
- Status line (#396): on the settings in two panes the frames draw `back` (`Esc`) between mail and commands; there
  `Esc` keeps the settings shown, so the line leaves it out. The sections' list alone in one pane draws it too; the
  line leaves it out there for the same reason.
- Status line (#396): a send counting down is a live region whose seconds change each second, so a screen reader may
  say it more than once; the frame says it once.
