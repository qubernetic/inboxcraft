## Changelog
### Added
- Two read-only MCP tools: `mail_why` (`mail.why`, by message `id`) says why a message stands where it does, at
  most four reasons a line with the sender's address quoted as untrusted, and `week_settings` (`week.settings`, no
  arguments) says how weeks are counted and which week today is; both run headless on a store and in the running
  app (#273)
