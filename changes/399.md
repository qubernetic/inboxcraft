## Changelog
### Added
- `ui.home.open` (`safe`, no parameters) is an engine command: the control channel, the CLI in the running app and
  an agent can show Home. An agent's call is passed over as an agent's `ui.settings.open` is (the account form holds
  what the owner typed, a key is being given) and while the owner edits an event in the window's event editor; the
  owner's own key or press in the same frame wins, and of an agent's calls of `ui.home.open` and `ui.settings.open`
  only the newest acts in a frame. On a store it shows nothing, and its answer says so with `"window": false` (#399)
