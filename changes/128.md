# 128

## Changelog
### Added
- Follow-up reminders: `mail.follow_up` (`safe`, `until` or a preset of `schedule.presets`) on a message the owner
  sent reminds them at that time if no reply came; a reply that arrives before then (its `In-Reply-To` or
  `References` names the sent message, and it is not from one of the owner's own addresses) cancels it, and at the
  time `Session::tick` tells the owner with a notice that opens the sent message (#128)
- `mail.cancel_follow_up` (`safe`) takes a reminder off, and `history.undo` takes either back (#128)
- `mail.list` says each row's `follow_up` (#128)

## Roadmap
- Follow-up reminders: "remind me if no reply by" on a sent message, cancelled by a synced reply, a notice that opens
  the sent message at the time, undoable (#128)

## Gaps
- A follow-up reminder is kept in this computer's store only: another InboxCraft does not see it. A reply is told
  only by its `In-Reply-To` or `References`, so a reply from a program that writes neither, or to a sent message
  without a Message-ID, does not cancel it; a reply that arrives while InboxCraft is off cancels it only if the sync
  brings it before the next tick, and an answer from the owner's own address never does. The window has no follow-up
  button or time picker yet (the UI slice) (#128).
